# 架构说明

```text
车牌相机/道闸 ──→ 设备接入层 ──→ 通行领域
车主H5 ─────────→ 业务API ─────→ 计费/优惠/支付
物业运营端 ──────→ 管理API ─────→ 车场/车位/月卡
                                    ↓
                              MySQL与审计流水
```

社区版使用内存领域对象与 JSON 快照，实现车位和通行记录的一致更新。生产部署建议在“车辆入场+车位占用”“支付+优惠核销”“离场+车位释放”三个边界使用数据库事务，并用分布式锁或唯一索引处理相机重复识别。

车牌识别、道闸控制和真实支付属于外部适配器；领域服务不依赖厂商SDK，可以按现场设备协议扩展。
